THE GREAT SHABI — BASIC WEBSITE BUILD

Contents:
- index.html
- assets/ with four real Shelton/Shabi photos from your uploads

How to use:
1. Unzip this folder.
2. Upload index.html and the assets folder to the root of the GitHub repository.
3. Netlify will redeploy automatically.

This is intentionally a simple, amateur-looking starting shell.
Replace, remove, or add real photos, clipart, fonts, logos, scans, audio and text as you create them.
